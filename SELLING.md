## Product Description

Build your own AI Companion web application with a modern futuristic glassmorphism interface.

This source-code package includes a responsive frontend, Express/JWT authentication, PostgreSQL conversation storage, OpenAI backend integration, Premium trial interface, optional Firebase Authentication integration, and setup documentation.

You get the source code and commercial usage license needed to customize the project for your own deployment.

You provide your own hosting, database, API keys, authentication project, domain, and third-party service accounts.

## Buyer Requirements

The buyer should be comfortable configuring:
- Node.js
- PostgreSQL
- Environment variables
- OpenAI API access
- Web hosting

Optional Firebase and payment integrations require additional configuration.

## Important Product Disclosure

The included Premium feature is a 7-day trial flow. It is not a complete recurring payment system. Buyers who want paid subscriptions must integrate and configure their own payment provider and subscription management.
