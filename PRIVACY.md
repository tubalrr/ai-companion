# AI Companion Privacy Notice

**Effective date:** September 22, 2026

AI Companion may process account information, conversation content, and technical information needed to operate the service.

## Account data
The backend stores an email address, display name, password hash, account timestamps, conversation metadata, and conversation messages when cloud sync is enabled.

Passwords are stored as password hashes rather than plaintext passwords.

## AI processing
Messages sent to the AI endpoint may be transmitted to the configured AI provider so that the requested response can be generated. Do not submit information you do not have permission to process.

## Security
The application is designed to keep API credentials on the server and uses an HTTP-only session cookie for authentication. No security system is guaranteed to be completely secure.
